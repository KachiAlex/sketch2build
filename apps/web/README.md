# Sketch2Build Web Frontend

React / Vite / TypeScript / TailwindCSS / shadcn/ui application.

## Pages

- `/` — Project dashboard
- Future: `/sketch`, `/prompt`, `/editor`, `/admin`

## Local development

```bash
# From repo root
npm install
npm run build -w packages/shared
npm run dev -w apps/web
```

## Environment

Copy `.env.example` to `.env` and configure.
